# コマンド一覧(プレイヤー用)

すべて `/ol <コマンド>` の形で実行できます。★の付いたものは `/ol` を付けずに単独のコマンド(例: `/guild`)としても実行できます。詳しい説明は各ページのリンク先を参照してください。`/ol help [ページ]` で一覧をゲーム内表示でき、`/ol help <コマンド名>` と指定するとそのコマンド1件だけの説明を表示します。

| コマンド | 説明 | 詳細 |
|---|---|---|
| `status`★ | ステータス画面を開く | [レベル・ステータス・職業](growth.md) |
| `skill` | 武器スキル画面を開く(ネザースター経由) | [戦闘・武器スキル](combat.md) |
| `job`★ | 現在の職業/職業一覧を確認 | [レベル・ステータス・職業](growth.md) |
| `craft`★ | 合成画面を開く | [装備・アイテム](items.md) |
| `relic upgrade`★(`relic`のみ) | レリックの厳選 | [装備・アイテム](items.md) |
| `item levelup [amount]` | 手持ち武器のレベルを上げる | [装備・アイテム](items.md) |
| `quest [list\|gui\|abandon <id>]`★(`quest`のみ) | クエストログの確認・放棄 | [クエスト・NPC](quest.md) |
| `title <list\|equip <称号>\|unequip>`★ | 称号の確認・装備 | [クエスト・NPC](quest.md) |
| `dungeon [list\|start <id> [難易度]\|retire]`★ | ダンジョンへの挑戦 | [ダンジョン](dungeon.md) |
| `party <...>`★ | パーティー管理 | [パーティー・ギルド・フレンド](social.md) |
| `guild <...>`★ | ギルド管理 | [パーティー・ギルド・フレンド](social.md) |
| `friend <...>`★ | フレンド管理 | [パーティー・ギルド・フレンド](social.md) |
| `chat <public\|party\|guild\|admin>`★ | チャットチャンネル切り替え | [チャット](chat.md) |
| `chat gui`★ | チャンネル切り替え・ミュート切り替えGUIを開く | [チャット](chat.md) |
| `chat mute <public\|party\|guild>`★ | チャットのミュート | [チャット](chat.md) |
| `msg <プレイヤー> <メッセージ>`★ | 個人チャット | [チャット](chat.md) |
| `trade <プレイヤー\|...>`★ | プレイヤー間取引(Orelia製の武器/アクセサリー/レリックのみ提示可) | [経済](economy.md) |
| `auction [list\|sell <価格>\|start <開始価格> [時間]\|bid <ID> <金額>\|collect]`★ | オークション(即決/入札形式) | [経済](economy.md) |
| `mail [unread\|send <player> <件名>\|delete <番号>]`★ | メール | [経済](economy.md) |
| `achievement [page\|gui]`★ | 実績の確認 | [実績・ランキング・称号](progress.md) |
| `ranking`★ | ランキングGUIを開く | [実績・ランキング・称号](progress.md) |
| `house <list\|buy <id>\|home\|gui>`★ | 住居 | [住居・ペット・乗り物](housing.md) |
| `pet <list\|buy <id>\|summon [id]\|dismiss\|gui>`★ | ペット | [住居・ペット・乗り物](housing.md) |
| `mount <list\|buy <id>\|summon [id]\|dismiss>`★ | 乗り物 | [住居・ペット・乗り物](housing.md) |
| `gathering`★ | 採取レベルの確認 | [採取](gathering.md) |

`dialoguechoice` は会話中のクリック選択肢から内部的に実行されるコマンドで、直接入力するものではありません。
