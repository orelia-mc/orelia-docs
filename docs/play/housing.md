# 住居・ペット・乗り物

## 住居

| コマンド | 説明 |
|---|---|
| `/ol house list` / `/ol house gui` | 購入可能な土地の一覧を表示します |
| `/ol house buy <土地ID>` | 土地を購入します |
| `/ol house home` | 自宅にテレポートします |

1人1軒までです。

## ペット

| コマンド | 説明 |
|---|---|
| `/ol pet list` / `/ol pet gui` | 購入可能なペットの一覧を表示します |
| `/ol pet buy <ペットID>` | 購入します |
| `/ol pet summon [ペットID]` | 呼び出します |
| `/ol pet dismiss` | 送り返します |

## 乗り物

| コマンド | 説明 |
|---|---|
| `/ol mount list` | 購入可能な乗り物の一覧を表示します |
| `/ol mount buy <乗り物ID>` | 購入します |
| `/ol mount summon [乗り物ID]` | 呼び出します |
| `/ol mount dismiss` | 送り返します |

ペット・乗り物は一度購入すれば恒久的に所持でき、何度でも呼び出し/送り返しができます。
