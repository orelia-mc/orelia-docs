# 住居・ペット・乗り物

## 住居

| コマンド | 説明 |
|---|---|
| `/ol house list` / `/ol house gui` | 購入可能な土地の一覧を表示します |
| `/ol house buy <土地ID>` | 土地を購入します |
| `/ol house home` | 自宅にテレポートします |

1人1軒までです。

## ペット

| コマンド | 説明 |
|---|---|
| `/ol pet list` / `/ol pet gui` | 購入可能なペットの一覧を表示します |
| `/ol pet buy <ペットID>` | 購入します |
| `/ol pet summon [ペットID]` | 呼び出します |
| `/ol pet dismiss` | 送り返します |

## 乗り物

| コマンド | 説明 |
|---|---|
| `/ol mount list` | 購入可能な乗り物の一覧を表示します |
| `/ol mount buy <乗り物ID>` | 購入します |
| `/ol mount summon [乗り物ID]` | 呼び出します |
| `/ol mount dismiss` | 送り返します |

ペット・乗り物は一度購入すれば恒久的に所持でき、何度でも呼び出し/送り返しができます。

### 成長(種族によっては非対応)

種族によっては、呼び出している間にOreliaのモンスター(タグ付きモンスター、バニラの通常モブは対象外)を倒すと経験値が入り、レベルアップでステータスボーナス(攻撃力・防御力・会心率・移動速度など、種族ごとに異なる)を得られます。レベルアップするとチャットで通知が届きます。レベルと経験値は種族(ペットID/乗り物ID)ごとに個別に記録され、購入済みの他の種族に持ち越されることはありません。ボーナスは呼び出している間だけ適用され、送り返す・ログアウトするなど呼び出しが終わると外れます(同時に有効になるのは、そのとき呼び出している1体分だけです)。

すべての種族が成長するわけではなく、成長に対応していない種族は今まで通り見た目だけの純粋なペット/乗り物です。
