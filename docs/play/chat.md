# チャット

## チャンネル

デフォルトの全体チャットに加えて、パーティー/ギルドに所属していれば専用チャンネルに切り替えられます。

- `/ol chat` — 現在選択中のチャンネルを表示します。
- `/ol chat <public|party|guild|admin>` — チャンネルを切り替えます(`admin`は管理者権限が必要です)。
- 一度切り替えると、以降の通常のチャット発言がすべてそのチャンネルに送られます。`/party chat <メッセージ>`・`/guild chat <メッセージ>` のように、チャンネルを切り替えずに1回だけ送ることもできます。

パーティー/ギルドを抜けた状態でそのチャンネルを選んでいた場合は、自動的に全体チャットへ戻されます。

## ミュート

`/chat mute <public|party|guild>` で、自分が **実際にタイプしたチャットだけ** をチャンネル単位でミュートできます。もう一度同じカテゴリを指定するとミュート解除です。引数なしで実行すると、現在ミュート中のカテゴリを確認できます。

- ミュートできるのは全体・パーティー・ギルドの3チャンネルの発言のみです。
- パーティー招待・ギルド招待・取引申込・メール未読通知のような、システムから届く通知(メッセージ本体とサウンド)はミュートの対象外で、常に届きます。

サーバー設定によっては `/chat mute` 自体が無効化されている場合があります。
