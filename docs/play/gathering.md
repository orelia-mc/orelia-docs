# 採取(釣り・木こり・採掘・農業)

木こり・採掘師・農民・釣り人には、戦闘とは別に独立した職業レベルがあります。`/ol gathering` で現在のレベルを確認できます。

## 木こり・採掘師

該当する職業であれば、天然のブロック(木・鉱石など)を伐採/採掘するとレベルが上がります。伐採/採掘したブロックはしばらくすると自動で再生成されます。街中の装飾木など、再生成させたくない場所は保護されている場合があります(サーバー設定による)。

## 農民

該当する職業であれば、しゃがみながら収穫すると周囲の作物をまとめて収穫できます。

## 釣り人

釣り人レベルが上がるほど、浮きが沈むまでの待ち時間が短くなります。釣れるアイテムはエリアごとに異なる抽選テーブルで決まります(浮きの位置に応じて変わることがあります)。

## 職業と武器

いずれも対応する職業を選んでいないと専用の恩恵(レベルアップ・一括収穫など)を得られません。職業の選び方は[レベル・ステータス・職業](growth.md)を参照してください。
