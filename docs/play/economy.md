# 経済(ショップ・トレード・オークション・メール)

## ショップ

武器・防具・アクセサリー・レリックなどを扱うショップNPCに話しかけると購入画面が開きます。お金が動く操作なので、購入前に確認画面が表示されます。

## トレード(プレイヤー間取引)

`/trade <プレイヤー名>` で取引を申し込みます。提示できるのはOreliaの武器・アクセサリー・レリックだけです(バニラのアイテムやネザースターなどは提示できません)。

| コマンド | 説明 |
|---|---|
| `/trade <プレイヤー名>` | 取引を申し込みます |
| `/trade accept` | 申し込みに応じます |
| `/trade add` | 手に持っているアイテムを提示します |
| `/trade remove <番号>` | 提示したアイテムを取り戻します |
| `/trade money <金額>` | 提示金額を設定します |
| `/trade confirm` | 取引を確定します(双方が確定すると成立) |
| `/trade cancel` | 取引をキャンセルします |
| `/trade view` | お互いの提示内容を表示します |

申し込み・取引セッションのどちらも一定時間で自動的にタイムアウトします。

## オークション

`/ol auction`(引数なし、または`list`)で出品一覧のGUIを開きます。出品には即決の「通常出品」と、期限まで入札を受け付ける「入札形式」の2種類があります。出品できるのはトレードと同じくOreliaの武器・アクセサリー・レリックだけです。

| コマンド | 説明 |
|---|---|
| `/ol auction` / `/ol auction list` | 出品一覧のGUIを開きます |
| `/ol auction sell <価格>` | 手に持っているアイテムを、その価格で即決出品します |
| `/ol auction start <開始価格> [時間(h)]` | 手に持っているアイテムを、入札形式で出品します(時間省略時はサーバー設定の既定期間) |
| `/ol auction bid <出品ID> <金額>` | 入札形式の出品に入札します(GUIから入札する方が簡単です) |
| `/ol auction collect` | 売却済み代金・未売却/入札の無かったアイテムをまとめて回収します |

入札形式では、入札した時点で金額がすぐ引き落とされ、後から誰かに上回られると自動的に返金されます(上回られた際はメールでも通知が届きます)。入札できる最低額は「現在の最高額 × (1 + 最低上昇率)」で、サーバー設定によります。GUIで他人の出品をクリックすると、即決購入/入札の前に確認画面が挟まります(誤クリック防止。自分の出品を取り下げる操作には確認はありません)。

売れる(または落札される)と手数料が差し引かれた金額がメールで届きます(下記メール参照)。出品数の上限や出品期間はサーバー設定によります。

## メール

`/ol mail` で受信箱を開きます。

| コマンド | 説明 |
|---|---|
| `/ol mail` / `/ol mail unread` | 受信箱を開きます |
| `/ol mail send <プレイヤー名> <件名...>` | メールを送ります |
| `/ol mail delete <番号>` | メールを削除します |

参加後しばらくすると、未読メールがあれば通知が届きます(クリックで受信箱を開けます)。オークションの売上通知・入札で上回られた際の通知など、システムからのメールもここに届きます。
