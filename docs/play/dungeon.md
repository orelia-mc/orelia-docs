# ダンジョン

## 発見と挑戦

1. マップ上に設置されたダンジョン開放ブロックを右クリックすると、初回はダンジョンを「発見」します(このプレイヤーに永続保存されます)。
2. もう一度クリックするか `/ol dungeon` でGUIを開くと、難易度選択画面が表示されます。
3. 難易度は5/10/15/20/30/40/50/60/70/80/90/100の固定ティアから、**自分のキャラクターレベル以下** のものだけを選べます(選べるティアがなければ「通常」=スケーリングなしになります)。
4. 難易度を選ぶとその場でアリーナが確保され(空きがなければ「満員」で拒否されます)、カウントダウン(Title表示)の後に敵が配置されたエリアへテレポートします。

コマンドでも操作できます。

- `/ol dungeon list` — 発見済みダンジョンの一覧
- `/ol dungeon start <ダンジョンID> [難易度]` — 直接挑戦を開始
- `/ol dungeon retire` — いつでも自主離脱(報酬なし、発見状態は失われず再挑戦可能)

## パーティーでの挑戦

挑戦者が[パーティー](social.md)を組んでいる場合、オンラインのメンバー全員が同行します。組んでいなければソロで挑戦します。ダンジョンを発見済みかのチェックは、パーティーリーダーに対してのみ行われます。

## クリアと報酬

設定された敵とボスを制限時間内に全滅させればクリアです。

- 経験値・所持金を獲得します(チャットに表示されます)。
- ボスがいるダンジョンをクリアすると、メンバーそれぞれに[レリック](items.md)がドロップします(個数は個別に表示されます)。
- 一部のクエストの「ダンジョンクリア」目標が進行します。

制限時間切れは報酬なしで強制退出になります(発見状態は失われません)。
