# パーティー・ギルド・フレンド

パーティー・ギルド・フレンドはいずれも、コマンドと専用GUIの両方から同じ操作ができます。GUIは `/party gui`・`/guild gui`・`/friend gui`(または `/ol party gui` のように `/ol` 経由でも同じ)で開けます。

GUIでギルド名・招待するプレイヤー名・チャットメッセージのような自由な文章を入力する場面では、ボタンを押すとGUIが閉じて「チャットに入力してください」と案内が出ます。そのままチャット欄に入力してEnterを押すと、その内容が実行されます。

## パーティー

一時的なグループです(サーバー再起動で解散します)。

| コマンド | 説明 |
|---|---|
| `/party create` | パーティーを作成します |
| `/party invite <プレイヤー名>` | 招待します(リーダーのみ) |
| `/party accept` / `/party decline` | 招待を承認/拒否します |
| `/party leave` | 脱退します(リーダーは脱退できません。解散するか、先にリーダーを譲ってください) |
| `/party kick <プレイヤー名>` | 追放します(リーダーのみ) |
| `/party transfer <プレイヤー名>` | リーダー権限を譲ります |
| `/party disband` | 解散します(リーダーのみ) |
| `/party list` | メンバー一覧を表示します |
| `/party chat <メッセージ>` | パーティーチャットに送信します |

GUIでは、メンバーの頭アイコンをクリックすると(リーダーの場合)追放・リーダー譲渡ができる操作画面が開きます。招待が届いている間は、GUIの一覧画面に承認/拒否ボタンが表示されます。

## ギルド

永続的な組織です。リーダー・幹部・メンバーの3つの役職があります。

| コマンド | 説明 |
|---|---|
| `/guild create <名前> <タグ>` | ギルドを作成します(名前は16文字・タグは5文字まで、既存のギルドと同じ名前/タグは使えません) |
| `/guild invite <プレイヤー名>` | 招待します(リーダー・幹部) |
| `/guild accept` | 招待を承認します |
| `/guild leave` | 脱退します(リーダーは脱退できません) |
| `/guild kick <プレイヤー名>` | 追放します(リーダー・幹部) |
| `/guild promote <プレイヤー名>` / `/guild demote <プレイヤー名>` | 昇格/降格させます(リーダーのみ) |
| `/guild transfer <プレイヤー名>` | リーダー権限を譲ります(リーダーのみ) |
| `/guild disband` | 解散します(リーダーのみ) |
| `/guild list` / `/guild info` | ギルド一覧/自分のギルド情報を表示します |
| `/guild chat <メッセージ>` | ギルドチャットに送信します |

GUIでは、一覧画面から他のギルドの詳細(メンバー一覧)を確認できます。自分のギルドのメンバーの頭アイコンをクリックすると、権限に応じた操作画面(昇格/降格/リーダー譲渡/追放)が開きます。未所属時は一覧画面に「ギルドを作成」ボタンが、招待が届いている間は承認/拒否ボタンが表示されます。

## フレンド

永続的な相互フレンド関係です。

| コマンド | 説明 |
|---|---|
| `/friend add <プレイヤー名>` | フレンド申請を送ります |
| `/friend accept` / `/friend decline` | 申請を承認/拒否します |
| `/friend remove <プレイヤー名>` | フレンドを解除します |
| `/friend list` | フレンド一覧を表示します(オンライン/オフライン表示付き) |
| `/friend tpa <プレイヤー名>` | テレポート申請を送ります |
| `/friend tpaccept` / `/friend tpdecline` | テレポート申請を承認/拒否します |

GUIでは、フレンドの頭アイコンをクリックでテレポート申請、Shift+クリックでフレンド解除ができます。申請が届いている間は一覧画面に承認/拒否ボタンが表示されます。
