# パーティー・ギルド・フレンド

パーティー・ギルド・フレンドはいずれも、コマンドと専用GUIの両方から同じ操作ができます。`/party`・`/guild`・`/friend`(それぞれ `/p`・`/g`・`/f` という1文字短縮形も使えます)を引数なしで実行すると、そのままGUIが開きます。`/ol party gui`のように`/ol`経由・`gui`引数付きで開くのも同じ結果です。ネザースターのプレイヤー情報メニューにも同じGUIを開くショートカットボタンがあります([はじめに](index.md)参照)。

GUIでギルド名・招待するプレイヤー名・チャットメッセージのような自由な文章を入力する場面では、ボタンを押すとGUIが閉じて「チャットに入力してください」と案内が出ます。そのままチャット欄に入力してEnterを押すと、その内容が実行されます。

招待・申請は複数人から同時に届くことがあります。コマンドで`accept`/`decline`する際に対象を省略すると一番古い1件が対象になり、名前を指定するとその相手からの招待/申請だけを個別に承認/拒否できます。GUIでは「招待/申請が届いています」ボタンから一覧を開き、1件ずつ承認/拒否できます。

## パーティー

一時的なグループです(サーバー再起動で解散します)。

| コマンド | 説明 |
|---|---|
| `/party create` | パーティーを作成します |
| `/party invite <プレイヤー名>` | 招待します(リーダーのみ) |
| `/party accept [リーダー名]` / `/party decline [リーダー名]` | 招待を承認/拒否します(省略時は一番古い招待が対象) |
| `/party leave` | 脱退します(リーダーは脱退できません。解散するか、先にリーダーを譲ってください) |
| `/party kick <プレイヤー名>` | 追放します(リーダーのみ) |
| `/party transfer <プレイヤー名>` | リーダー権限を譲ります |
| `/party disband` | 解散します(リーダーのみ) |
| `/party list` | メンバー一覧を表示します |
| `/party chat <メッセージ>` | パーティーチャットに送信します(チャンネルを切り替えず1回だけ送信) |

GUIでは、メンバーの頭アイコンをクリックすると(リーダーの場合)追放・リーダー譲渡ができる操作画面が開きます。「チャットに切り替え」ボタンは`/chat party`と同じで、以降の通常のチャット発言をパーティーチャットに切り替えます(1回だけ送るチャット欄ではありません)。招待が届いている間はGUI上部にボタンが表示され、クリックで一覧を開いて1件ずつ承認/拒否できます。

## ギルド

永続的な組織です。役職はリーダーと、ギルドごとに自由に作成できるカスタムロール(最大7個)で構成されます。招待・追放・ロール管理・改名・リーダー譲渡といった管理操作はすべてリーダーのみが行えます(ロールはメンバーの表示上の肩書きで、権限そのものは付与しません)。

| コマンド | 説明 |
|---|---|
| `/guild create <名前> <タグ>` | ギルドを作成します(名前は16文字・タグは5文字まで、既存のギルドと同じ名前/タグは使えません) |
| `/guild rename <新しい名前>` | ギルド名を変更します(リーダーのみ) |
| `/guild retag <新しいタグ>` | タグを変更します(リーダーのみ) |
| `/guild invite <プレイヤー名>` | 招待します(リーダーのみ) |
| `/guild accept [ギルド名]` / `/guild decline [ギルド名]` | 招待を承認/拒否します(省略時は一番古い招待が対象) |
| `/guild leave` | 脱退します(リーダーは脱退できません) |
| `/guild kick <プレイヤー名>` | 追放します(リーダーのみ) |
| `/guild addrole <ロール名>` / `/guild removerole <ロール名>` / `/guild renamerole <ロール名> <新しい名前>` | カスタムロールの追加・削除・改名をします(リーダーのみ、最大7個。割り当て済みのメンバーがいるロールは削除できません) |
| `/guild role <プレイヤー名> <ロール名>` | メンバーにロールを割り当てます(リーダーのみ) |
| `/guild transfer <プレイヤー名>` | リーダー権限を譲ります(リーダーのみ) |
| `/guild disband` | 解散します(リーダーのみ) |
| `/guild list` / `/guild info` | ギルド一覧/自分のギルド情報を表示します |
| `/guild chat <メッセージ>` | ギルドチャットに送信します(チャンネルを切り替えず1回だけ送信) |

GUIでは、一覧画面から他のギルドの詳細(メンバー一覧)を確認できます。自分のギルドでリーダーの場合、招待・改名・タグ変更・ロール管理のボタンが追加で表示されます。メンバーの頭アイコンをクリックすると(リーダーの場合)ロール変更・リーダー譲渡・追放ができる操作画面が開きます。「チャットに切り替え」ボタンは`/chat guild`と同じで、以降の通常のチャット発言をギルドチャットに切り替えます。未所属時は一覧画面に「ギルドを作成」ボタンが、招待が届いている間は届いている招待一覧を開くボタンが表示されます。

## フレンド

永続的な相互フレンド関係です。

| コマンド | 説明 |
|---|---|
| `/friend add <プレイヤー名>` | フレンド申請を送ります |
| `/friend accept [プレイヤー名]` / `/friend decline [プレイヤー名]` | 申請を承認/拒否します(省略時は一番古い申請が対象) |
| `/friend remove <プレイヤー名>` | フレンドを解除します |
| `/friend list` | フレンド一覧を表示します(オンライン/オフライン表示付き) |
| `/friend tpa <プレイヤー名>` | テレポート申請を送ります |
| `/friend tpaccept` / `/friend tpdecline` | テレポート申請を承認/拒否します |

GUIでは、フレンドの頭アイコンをクリックでテレポート申請、Shift+クリックでフレンド解除ができます。申請が届いている間は上部のボタンから一覧を開いて1件ずつ承認/拒否できます。
